# 🥗 Claude Nutritionist Workflow

Sistema de coaching nutricional pessoal usando Claude como seu nutricionista.

---

## 📁 Arquivos Neste Diretório

### 1. **NUTRITIONIST_PROMPT.md**
Script completo que você cola em uma **nova conversa** com Claude para começar.

**Como usar:**
1. Abra https://claude.ai (ou Claude em qualquer plataforma)
2. Crie uma **nova conversa**
3. Cole todo o conteúdo de `NUTRITIONIST_PROMPT.md`
4. Responda às perguntas iniciais dele
5. Comece a conversa!

### 2. **SKILL_NUTRITIONIST.md**
Instrução detalhada de como Claude deve atuar como nutricionista.

**Para usar como Skill (Claude Code):**
1. Copie o conteúdo
2. Crie um arquivo `.claude/skills/nutritionist.md` no seu projeto
3. Use `/nutritionist` para invocar

## 📊 O Que Você Pode Fazer

### Registrar Refeições
```
Almocei: arroz, feijão, frango grelhado, salada de alface, tomate e azeite. 
Dei uma bebida açucarada de 300ml depois.
```

Claude vai analisar, explicar calorias, macros, e sugerir melhorias.

### Fazer Perguntas
```
Por que quando como carboidrato simples sinto mais fome depois?
```

Claude vai explicar a ciência de forma simples.

### Contar Desafios
```
Tenho tido fome emocional à noite, especialmente quando estresso no trabalho.
```

Claude vai ajudar a entender e criar estratégias.

### Pedir Recomendações
```
Preciso de um snack rápido que sacia, alto em proteína, sem açúcar.
```

Claude vai sugerir opções práticas.

## 💡 Dicas de Uso

### ✅ O Que Funciona Bem
- Ser **honesto** sobre o que comeu (sem julgamento dele!)
- Contar **tudo**, até os "deslizes"
- Fazer **perguntas específicas** (não genéricas)
- Registrar **regularmente** (não precisa ser perfeito)
- Manter **contexto** (cansaço, stress, eventos)

### ❌ O Que NÃO Fazer
- Mentir sobre o que comeu
- Esperar perfeição
- Comparar com outras pessoas
- Usar para autossabotagem ("como assim, uma fatia de bolo?")
- Abandonar se tiver um dia ruim

---

## 📈 Estrutura de Progresso

### Semana 1-2: Baseline
- Entender seus hábitos atuais
- Identificar padrões
- Definir 1-2 mudanças pequenas

### Semana 3-4: Implementação
- Fazer as mudanças simples
- Ajustar conforme necessário
- Começar a ver diferenças

### Mês 2+: Evolução
- Adicionar novas mudanças
- Refinar o que funciona
- Manter sustentabilidade

---

## 🎯 Objetivos Recomendados

**Para Perda de Peso Saudável:**
- 0.5-1kg por semana é realista
- Não é uma corrida, é uma maratona
- Foco em hábitos, não em números

**Para Saúde:**
- Mais energia
- Melhor digestão
- Pele melhor
- Dormir melhor
- Clareza mental

- **Mensalmente**: Análise completa do progresso
- **A qualquer hora**: Quando tiver dúvidas ou desafios

## 🆘 Quando Procurar Profissional

Se você tiver:
- ❌ Condições médicas específicas (diabetes, colesterol alto)
- ❌ Histórico de distúrbios alimentares
- ❌ Necessidade de medicamentos relacionados
- ❌ Alergias/intolerâncias sérias

**Sempre consulte um nutricionista ou médico de verdade.**

Claude é um coach excelente, mas não substitui profissional de saúde quando necessário.
